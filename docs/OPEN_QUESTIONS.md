[남아 있는 질문]

1) 아키텍처 및 배포
- MES Web Service와 AI Middleware를 한 시스템으로 같이 운영할지, 분리해서 운영할지?
  이유: 함께 운영하면 관리가 쉽고, 분리하면 확장/장애 격리가 쉬워집니다.
- “단일 exe 배포”를 어떤 도구로 구현할지?
  이유: Windows/Linux에서 모두 동작해야 하고, DB 포함 설치가 필요합니다.

2) 인증/보안 정책
- 기본 관리자 계정과 초기 비밀번호 정책을 어떻게 할지?
- 비밀번호 규칙(길이, 문자/숫자/특수문자)과 잠금 정책(로그인 실패 횟수)은?
- JWT 사용 시 만료 시간과 저장 위치는?
  이유: 보안과 사용자 편의성의 균형을 맞추기 위해 필요합니다.

3) AI Middleware 기준
- 자동 분류 신뢰도 임계치(예: 0.85)를 어디로 설정할지?
- AI/ML/LLM을 JVM 내부에서 돌릴지, 별도 서비스로 분리할지?
  이유: 운영 비용과 정확도, 유지보수 방식이 크게 달라집니다.

4) 운영 정책
- 원시 로그 보관 기간을 기본 30일로 할지, 기업별 설정을 허용할지?
- 백업 주기와 저장 위치를 어떻게 할지?
  이유: 장애 대응과 데이터 복구를 위한 기본 정책입니다.
