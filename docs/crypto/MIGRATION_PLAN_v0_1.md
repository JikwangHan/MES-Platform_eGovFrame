MIGRATION_PLAN_v0_1

목적
- 무료 구현 → KCMVP 검증필 모듈 전환 절차를 데이터 포맷 변경 없이 수행합니다.
- 외부 입력(공급사 자료) 없이 무료 오픈소스 구현을 기본 적용합니다.

전제 조건
- CryptoService/crypto boundary 구현 완료
- 암호문 컨테이너 포맷 고정
- 키 계층 및 회전 워크플로 구현

전환 단계
1) 컨테이너 포맷 v1 동결
- 파서/시리얼라이저 변경 금지

2) KCMVP provider/구현체 placeholder 적용
- 인터페이스 유지, 구현체만 교체 가능하도록 유지
 - 패턴 C의 HSM 인터페이스는 개발 단계에서 비활성 상태 유지

3) 형상데이터(해시) 봉인 절차 적용
- 릴리즈 산출물 SHA-256 생성
- 2인 승인 후 봉인
- 벤더 제공 해시와 일치 여부 자동 검증 스크립트 운영

4) 재암호화 계획
- key_version 기준 범위별 배치 재암호화
- Retired 키로 복호 호환 유지

5) 롤백 전략
- 이전 provider 유지
- Retired 키 보관으로 복호 복원 가능

6) 감사 증적 확보
- 해시/승인 로그/테스트 결과 보관

주의
- 개발 단계는 무료 구현, 상용화 단계에서 검증필 모듈로 교체
- 포맷/정책은 무료 구현과 동일 유지
