# MES Web Service 스모크 테스트 기록 (2026-01-27-2)

## 목적
- 약관 모달 스타일 개선 및 이메일 발송 비활성 안내가 정상 표시되는지 확인한다.

## 환경
- 로컬 Tomcat 구동 환경
- 브라우저: 크롬 기반 브라우저

## 테스트 시나리오
1) 약관 모달 스타일 확인
   - 동작: 회원가입 화면에서 약관/개인정보 “전문보기” 클릭
   - 기대: 모달이 둥근 모서리와 정돈된 본문 스타일로 표시된다.
   - 결과: 정상 표시됨

2) 이메일 비활성 안내 확인
   - 동작: 이메일 입력 후 인증 화면 이동
   - 기대: 발송 비활성 시 안내 문구가 표시된다.
   - 결과: 정상 표시됨

## 참고
- 민감 정보(비밀번호/토큰/로컬 경로)는 기록하지 않음.
