# MES Web Service 스모크 테스트 기록 (2026-01-26)

## 목적
- 회원가입/인증/로그인 UI 및 기본 흐름이 정상 동작하는지 확인한다.

## 환경
- 로컬 Tomcat 구동 환경
- 브라우저: 크롬 기반 브라우저

## 테스트 시나리오
1) 회원가입 화면 진입 확인
   - 경로: /mes-web/signup
   - 기대: 회원가입 카드와 입력 폼이 정상 표시된다.
   - 결과: 정상 표시됨

2) 회원가입 필수값 검증 확인
   - 동작: 필수 약관 미동의 상태로 가입 시도
   - 기대: “필수 약관에 동의해 주세요.” 오류가 표시된다.
   - 결과: 정상 표시됨

3) 이메일 인증 흐름 확인
   - 동작: 이메일 입력 후 회원가입 진행
   - 기대: 인증 코드 입력 화면으로 이동한다.
   - 결과: 정상 이동됨

4) 로그인 화면 성공 메시지 확인
   - 동작: 회원가입 완료 후 로그인 화면 이동
   - 기대: 회원가입 성공 메시지가 표시된다.
   - 결과: 정상 표시됨

## 참고
- 민감 정보(비밀번호/토큰/로컬 경로)는 기록하지 않음.
