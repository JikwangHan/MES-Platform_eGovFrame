# MES Web Service 스모크 테스트 기록 (2026-01-27-4)

## 목적
- 승인 보류 사유 입력/거절 처리 및 승인/거절 알림 발송 흐름을 확인한다.

## 환경
- 로컬 Tomcat 구동 환경
- 브라우저: 크롬 기반 브라우저

## 테스트 시나리오
1) 반려 사유 필수 입력 확인
   - 동작: 반려 사유 없이 반려 버튼 클릭
   - 기대: “반려 사유를 입력해 주세요.” 오류 표시
   - 결과: 정상 표시됨

2) 승인/반려 처리 및 로그 확인
   - 동작: 사유 입력 후 승인/반려 버튼 클릭
   - 기대: 상태 변경 및 감사 로그 기록
   - 결과: 정상 확인됨

3) 승인/반려 알림 발송 확인
   - 동작: 승인/반려 처리 후 이메일 발송 시도
   - 기대: 승인/반려 알림 발송 로그 확인
   - 결과: 정상 확인됨

## 참고
- 민감 정보(비밀번호/토큰/로컬 경로)는 기록하지 않음.
