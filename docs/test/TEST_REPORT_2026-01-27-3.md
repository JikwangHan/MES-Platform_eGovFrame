# MES Web Service 스모크 테스트 기록 (2026-01-27-3)

## 목적
- 이메일 재시도/승인 알림 및 약관 전문 문구 변경이 정상 동작하는지 확인한다.

## 환경
- 로컬 Tomcat 구동 환경
- 브라우저: 크롬 기반 브라우저

## 테스트 시나리오
1) 이메일 재시도 설정 확인
   - 동작: SMTP 설정에 재시도 값 지정
   - 기대: 발송 실패 시 재시도 로그가 출력된다.
   - 결과: 정상 확인됨

2) 승인 알림 발송 흐름 확인
   - 동작: /admin/users에서 승인 버튼 클릭
   - 기대: 승인 알림 발송 시도 및 감사 로그 기록
   - 결과: 정상 확인됨

3) 약관 전문 문구 변경 확인
   - 동작: 회원가입 화면에서 약관 모달 열기
   - 기대: 수정된 약관/개인정보 문구가 표시됨
   - 결과: 정상 표시됨

## 참고
- 민감 정보(비밀번호/토큰/로컬 경로)는 기록하지 않음.
