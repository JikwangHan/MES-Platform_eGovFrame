# MES Web Service 스모크 테스트 기록 (2026-01-27)

## 목적
- 회원가입 약관 모달/이메일 발송/승인 UI가 정상 동작하는지 확인한다.

## 환경
- 로컬 Tomcat 구동 환경
- 브라우저: 크롬 기반 브라우저

## 테스트 시나리오
1) 약관 전문 모달 확인
   - 동작: 회원가입 화면에서 “전문보기” 클릭
   - 기대: 이용약관/개인정보 처리방침 모달이 열린다.
   - 결과: 정상 표시됨

2) 이메일 인증 안내 확인
   - 동작: 이메일 입력 후 회원가입 진행
   - 기대: 인증 화면에서 이메일 발송 상태 안내가 표시된다.
   - 결과: 정상 표시됨

3) 관리자 승인 UI 확인
   - 동작: /admin/users 화면에서 승인 대기 목록 확인
   - 기대: 승인 대기 사용자 목록과 승인 버튼이 표시된다.
   - 결과: 정상 표시됨

## 참고
- 민감 정보(비밀번호/토큰/로컬 경로)는 기록하지 않음.
